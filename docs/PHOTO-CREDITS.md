# Kredit gambar alat

Foto contoh diambil dari Wikimedia Commons dan Unsplash untuk keperluan demonstrasi tugas akademik. Sebagian besar gambar diakses dari URL sumber; enam gambar yang sebelumnya gagal dimuat disalin ke `app/public/tools/` agar stabil dan tidak bergantung pada proxy.

## Wikimedia Commons

- Proyektor: [BenQ DLP projector MP515](https://commons.wikimedia.org/wiki/File:BenQ_DLP_projector_MP515_20101213.jpg)
- Arduino: [Arduino Uno 006](https://commons.wikimedia.org/wiki/File:Arduino_Uno_006.jpg)
- Raspberry Pi: [Raspberry Pi 4 Model B - Top](https://commons.wikimedia.org/wiki/File:Raspberry_Pi_4_Model_B_-_Top.jpg)
- Multimeter: [Multimeter Gossen Metra Hit](https://commons.wikimedia.org/wiki/File:Multimeter_Gossen_Metra_Hit.jpg)
- Osiloskop: [Tektronix Oscilloscope 475A](https://commons.wikimedia.org/wiki/File:Tektronix_Oscilloscope_475A.jpg)

## Unsplash

- Laptop, router/kabel jaringan, bor, power supply, sensor kit.
- Switch, solder station, dan obeng memakai foto Unsplash pengganti di mirror lokal.
- Sumber: [Unsplash](https://unsplash.com/license) (lisensi Unsplash).

## Mirror lokal

`app/public/tools/` menyimpan ELK-002, ELK-003, ELK-004, JAR-002, KOM-001, dan KOM-002. Tiga foto pertama berasal dari Wikimedia Commons; tiga sisanya dari Unsplash.

## Proxy

Beberapa gambar Wikimedia diakses melalui [images.weserv.nl](https://images.weserv.nl) agar ukuran konsisten dan tidak membebani server Wikimedia. Jika gambar diganti, perbarui `database/seed.sql` dan kredit ini.
